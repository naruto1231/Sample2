# Sample2

HTML/CSS/JavaScriptで作成したレスポンシブ対応のサンプルLP(ランディングページ)です。

## 概要

CSS3のメディアクエリとjQueryを用いて、PC・タブレット・スマートフォンなど画面サイズに応じたレイアウト表示に対応したサンプルページです。

## ファイル構成

- `index.html` / `sample.html` : ページ本体
- `style.css` : スタイルシート
- `script.js` : 独自スクリプト
- `css3-mediaqueries.js` : IE8以下などメディアクエリ非対応ブラウザ向けの補完スクリプト
- `html5.js` : 古いブラウザでHTML5タグを認識させるための補完スクリプト(HTML5 Shiv)
- `jquery1.4.4.min.js` : jQuery本体
- 画像素材一式(`eyecatch*.jpg`, `mainImg.jpg`, `sample*.jpg`, `arrow.png` など)

## 使用技術

- HTML5
- CSS3(メディアクエリ)
- JavaScript / jQuery

## 動作確認

`index.html` をブラウザで開くことで表示を確認できます。
